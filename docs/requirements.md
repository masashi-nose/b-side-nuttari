# 要件定義（要約）

元の要件定義書（Claude Docs）の要点。判断に迷ったらここと CLAUDE.md を優先する。

## 目的と成功指標

- 目的：沼垂エリアの記録・発信、観光客の呼び込み、お店の支援、住民への情報共有
- 成功指標：「沼垂」「沼垂 観光」など沼垂関連ワードで検索上位に入る
  - 公開3か月後：ロングテール（例：沼垂 ランチ）主要10語で10位以内、「沼垂」「沼垂 観光」で30位以内
  - 公開1年後：主要30語で5位以内、「沼垂」「沼垂 観光」で10位以内

## 前提と制約

- 一人運営、東京から遠隔。更新が止まらない設計を最優先
- 予算：当面はドメイン代のみ。サーバーは無料枠。ゆくゆく広告・掲載料で収益化できる構造にしておく
- 沼垂テラス商店街の公式サイト（nuttari.jp）とは役割を分けた「非公式のエリアガイド」

## 対象エリア

沼垂テラス商店街、酒蔵・味噌蔵などの蔵元、沼垂白山神社、寺町など沼垂エリア全体。

## SEO

- 大手旅行サイトや公式観光サイトが強いので、まず具体的なワード（沼垂 ランチ／駐車場／行き方／読み方／酒蔵／カフェ）で記事を積み、そのあと「沼垂」「沼垂 観光」を狙う
- 一次情報（取材・自分で撮った写真）、内部リンク、構造化データ、情報の新しさ（最終確認日）
- 公開日から Google Search Console とアクセス解析を入れる

## MVPの機能

| 機能 | 内容 |
| --- | --- |
| トップ | カルーセル、キャッチコピーと紹介文、ピックアップ店舗、読みもの、エリアマップ、アクセス導線 |
| 店舗・スポット一覧 | 区分・ジャンルで絞り込み、地図、全件表示（見た目だけ畳む） |
| 店舗・スポット詳細 | 写真、ひとこと紹介、基本情報、地図アプリ、SNSアイコン、紹介文、最終確認日、登場する読みもの、近くのお店 |
| 読みもの一覧 | カテゴリで絞り込み（0本のカテゴリは出さない） |
| 記事詳細 | 本文（見出し・画像・店舗カード・引用）、登場したお店、シェア、次に読む |
| アクセス | 徒歩・バス・車と駐車場（中身はコードに直接書く） |
| このサイトについて | サイト名の由来、非公式の説明、お問い合わせ・掲載依頼・訂正フォーム（運営者の紹介は載せない） |
| プライバシーポリシー・404 |  |

後のフェーズ：モデルコース、イベント情報、英語ページ、店主による情報更新、お知らせ、収益化、出店者募集。「営業中で絞り込み」はフェーズ2。

## コピー（確定）

- キャッチコピー：沼垂の、すぐそばに。
- 紹介文：沼垂のお店とスポットをひとつにまとめました。新しいけど、どこか懐かしい。発酵と醸造のまちを、もっと身近に。
- ラベル：新潟・沼垂の非公式ガイド
- フッター注記：このサイトは沼垂テラス商店街の公式サイトではありません。

## 非機能要件

- スマホ最優先。Core Web Vitals の基準をすべて満たす
- ページごとの title / description、OGP、構造化データ、サイトマップ
- スマホからも Studio で店舗情報を直せる
- 運用費は当面ドメイン代のみ
- 画像の代替テキスト、十分なコントラスト
